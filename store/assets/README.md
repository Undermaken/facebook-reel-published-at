# Store image provenance

All artwork in this folder derives from this repository's original calendar/play icon and the original dancer illustration in `popup.html`. No Facebook logo, user photo, or downloaded third-party image is included.

The `01-date-on-reel.png` and `03-below-reel.png` images show a clearly labeled illustrative Reel page. The date badge is inserted by the actual extension running in Chromium. The `02-settings.png` images contain a screenshot of the actual extension popup, including its built-in illustration. These are explanatory store graphics, not captures of a real Facebook Reel.

The two promo images have no words so one copy can serve all five locales. The 128×128 store icon scales the chosen icon artwork to 96×96 and adds 16 transparent pixels on each side, following Chrome's icon sizing guidance. The extension package retains its original icon files.

For the final listing, a screenshot of a real Reel with the extension active would make the product behavior easier to verify. Capture only content you can publish and remove personal details before upload.
